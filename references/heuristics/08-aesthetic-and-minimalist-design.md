# H8 Aesthetic and Minimalist Design

Use when the UI includes page layout, dashboards, visual hierarchy, data density, cards, navigation, decorative media, content strategy, scanability, affordances, flat/minimal visual style, or empty states.

## Check

- Keep every visible element tied to the user's task, confidence, decision, or brand trust.
- Prioritize high-value content and de-emphasize secondary details.
- Use aesthetics to build clarity, trust, hierarchy, and brand fit.
- Remove decorative or repeated elements that compete with task content.
- Use progressive disclosure for rare details without hiding essential context.
- Preserve necessary information, labels, controls, and clickability signifiers; sparse is not automatically minimalist.
- Write and structure content for scanning because users read only a fraction of typical page text.
- Maximize signal and minimize noise: favor high-information labels, clear signifiers, plain language, useful imagery, and helper text.
- Use visual design principles deliberately: scale, hierarchy, balance, contrast, proximity, grouping, and figure/ground.
- Avoid flat-design purity when it makes buttons, links, fields, active states, or layers hard to recognize.

## Content and Scanability

- Put the most important message, decision, or action first.
- Use concise headings, short paragraphs, lists, tables, labels, and summaries so users can extract meaning without reading everything.
- Cut low-information marketing copy, repeated instructions, redundant labels, unexplained jargon, filler imagery, and decorative text.
- Keep critical caveats, status, requirements, and consequences visible at the decision point.
- Use progressive disclosure for rare, advanced, or secondary details, not for information required to complete the core task.

## Visual Hierarchy

- Use scale to signal relative importance; avoid too many competing type sizes.
- Guide attention through hierarchy: size, weight, color, value, spacing, placement, and grouping.
- Balance visual weight so no decorative or secondary region dominates the main task.
- Use contrast to separate important differences, but preserve legibility and accessibility.
- Use Gestalt grouping: place related labels, controls, values, and actions close together and separate unrelated groups.

## Minimalism and Affordance

- Minimalist design means just enough useful content and controls, not the fewest possible elements.
- Keep interactive elements recognizable through shape, underline, color, depth, placement, labels, or other clear signifiers.
- Use subtle depth, boundaries, shadows, or layers when they clarify hierarchy or clickability.
- Avoid using the same visual treatment for links, buttons, selected items, disabled items, and static text.
- Treat whitespace as purposeful structure; empty space that hides useful guidance is not helpful minimalism.

## Evidence

Look for clear hierarchy, calm density, concise scannable copy, meaningful grouping, purposeful whitespace, accessible contrast, visible primary action, recognizable links/buttons/fields, useful imagery, progressive disclosure, and restrained decoration.

## Failure Patterns

- Visual flourish competes with the task.
- Cards, borders, or panels make the page harder to scan.
- Minimalism removes labels, context, or needed controls.
- Empty whitespace replaces useful guidance or data.
- Important content is buried in long prose that users are unlikely to read.
- Flat styling makes clickable elements indistinguishable from static text.
- Color, scale, or imagery draws attention away from the most important task element.
- Low-contrast text is used to de-emphasize content until it becomes hard to read.
- Related labels, fields, or actions are visually separated, while unrelated items look grouped.
- Decorative imagery, animation, cards, shadows, or textures add visual noise without helping comprehension.
